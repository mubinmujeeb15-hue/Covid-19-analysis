📌COVID_19_ANALYSIS
COVID-19 Data Analytics project using Python, Pandas, Jupyter Notebook, and Power BI to analyze cases, deaths, recoveries, mortality rates, and country/continent-level trends through data analysis and interactive dashboards.
📊 COVID-19 Data Analytics

📌 Project Overview

This project analyzes COVID-19 data to identify patterns and insights related to cases, deaths, recoveries, mortality rates, and population-adjusted cases.

⚙️ Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Power BI
* Jupyter Notebook

📊 Analysis Performed

* Data cleaning and preprocessing
* COVID-19 cases analysis
* Deaths and recovery analysis
* Country-wise comparison
* Continent-wise analysis
* Death rate analysis
* Recovery rate analysis
* Cases per 100K population
* Interactive Power BI dashboard

🎯 Key Insights

* USA had the highest reported total cases in the dataset.
* USA also recorded the highest number of deaths.
* Europe had the largest regional case burden.
* Recovery rates were very high in several heavily affected countries.
* Population-adjusted analysis produced different rankings from total-case analysis.
* Mortality rates varied significantly between countries.

📌 Dashboard

The Power BI dashboard provides an interactive view of COVID-19 cases, deaths, recovery rates, and country/continent-level comparisons.
